\# Turbofan 3D Visualizer



A real-time 3D turbofan engine visualization and simulation project built using \*\*C++, Raylib, and MediaPipe\*\*.



The project combines 3D graphics, real-time engine telemetry, audio simulation, and hand gesture control to create an interactive turbofan engine visualizer.



\## 🚀 Features



\- Real-time 3D turbofan engine visualization

\- Rotating fan, compressor, and turbine stages

\- Real-time RPM control

\- RPM gauge and live RPM graph

\- Temperature and pressure telemetry

\- Combustion and exhaust flame visualization

\- Engine start/stop control

\- Camera rotation and zoom

\- Realistic engine audio

\- Hand gesture control using MediaPipe

\- C++ and Raylib based rendering



\## ✋ Hand Gesture Controls



| Gesture | Action |

|---|---|

| ✊ Fist | Decrease RPM |

| 🖐️ Open Hand | Increase RPM |

| ☝️ One Finger | Start / Stop Engine |

| ✌️ Two Fingers | RPM Boost |

| 🤟 Three Fingers | Normal Mode |



RPM range: \*\*1000 – 10000 RPM\*\*
